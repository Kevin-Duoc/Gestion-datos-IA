# Gesti-n-datos-IA
Proyecto de la asignatura de Gestión de Datos de Inteligencia Artificial

# Nombre del proyecto
# IgneIA

# Descripcion del proyecto
El objetivo de este proyecto es describir la arquitectura técnica y la solución que se desarrollará, sirviendo como referencia base para el desarrollo posterior. El sistema consiste en un pipeline de datos diseñado para evaluar el riesgo de incendios forestales en la Región de Valparaíso. Su propósito principal es extraer variables meteorológicas en tiempo real, combinarlas con datos históricos de la zona y procesarlas mediante un modelo de clasificación de Machine Learning. El resultado será un "Semáforo de Riesgo" visual que alerte sobre las condiciones propicias para un incendio.


# Componentes principales 

-- **Base de datos PostgreSQL**: para la carga y consulta estructurada de los datasets.
- **Modelo de IA (scikit-learn)**: clasificación binaria para predecir agotamiento.
- **Metabase (opcional)**: dashboard de visualización de resultados.
